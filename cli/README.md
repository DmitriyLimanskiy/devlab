# DevLab CLI

Первая локальная версия CLI: приветствие DevLab и настоящая интерактивная оболочка bash через PTY. Целевая платформа — macOS, Python 3.11+. Используется первый `bash` из `PATH`; отдельные Python-зависимости для выполнения не нужны.

## Установка для разработки

В терминале:

```sh
cd /Users/dmitriysurov/Documents/projects/dev-lab/cli
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
devlab
```

После установки и активации окружения `devlab` можно запускать из любой папки. Bash стартует в текущем каталоге. Выбор папки внутри CLI пока отсутствует.

Без установки пакета, из папки `cli/`:

```sh
PYTHONPATH=src python3 -m devlab
```

## Работа

Внутри сессии доступны обычные команды bash и установленные программы. DevLab не интерпретирует команды самостоятельно. Единственная подсказка управления сейчас — выход:

- `exit` — завершить bash и DevLab, вернуться в исходную оболочку.
- `Ctrl+D` на пустой строке — тот же выход.

`Ctrl+C` прерывает текущую команду. Размер окна передаётся вложенному терминалу. Код завершения bash становится кодом завершения DevLab. Аргументы запуска пока не поддерживаются.

Оформление: компактный баннер, бирюзовый акцент и приглашение `devlab <каталог> >`. Для отключения цвета: `NO_COLOR=1 devlab`.

Bash запускается с временным rc-файлом: пользовательские `.bashrc` и login-профили не загружаются, история сессии не сохраняется в файл. Настройки пользователя на диске не меняются; переменные окружения и `PATH` наследуются. Это делает первый прототип предсказуемым; интеграцию пользовательских конфигураций нужно проработать отдельно.

## Проверка

```sh
python3 -m unittest discover -s tests -v
```

Тесты запускают реальный bash через вложенный PTY: команды, изменение размера, `Ctrl+C`, `exit`, `Ctrl+D`, код завершения и восстановление режима терминала. Для ручной проверки также запустите редактор, например `vi`, выйдите из него и из DevLab. Поддержка Linux и Windows пока не заявляется.

## Границы версии

Это основа терминальной сессии, а не готовая Git-песочница. Чтение Git, сигнал завершения команд, выбор проекта, привязка к браузеру, наблюдение за файлами и синхронизация с сервером ещё не реализованы.
