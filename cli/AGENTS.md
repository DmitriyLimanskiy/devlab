# Stack Forge CLI

Текущая задача CLI — запросить папку проекта, вывести выбранный путь и завершиться.

Точка входа — `src/main.py`. Команда `stackforge` и запуск модуля `python -m stack_forge` используют одну точку входа. При добавлении новых возможностей группировать код по бизнес-фичам.

Поддерживать абсолютные и относительные пути, `~`, выбор текущей папки по Enter и отмену по Ctrl+C или Ctrl+D.
