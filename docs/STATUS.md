# Текущее состояние DevLab

Обновлено 30 октября 2026 года. Этот документ отражает реализацию, а не постоянные инструкции разработки.

- CLI: macOS + bash, выбор папки до запуска, PTY, чтение Git после команд и внешних изменений. Снимок сохраняется в `state.json`, правило добавляется в `.gitignore`. Сетевой отправки пока нет.
- Backend: `GET /api/v1/catalog` возвращает статический список с Git; `GET /api/v1/git-course` возвращает заглушку `{"data": "data"}`. Сессии, приём снимков, WebSocket и подключение PostgreSQL ещё не реализованы.
- Frontend: `/catalog` — каталог, `/git-course` — страница Git; `/` переводится в каталог. Страница Git показывает инструкцию и пустые панели, без получения снимков CLI. Учебные материалы пока отсутствуют.
- Compose: nginx раздаёт сборку frontend, backend запускается с bind mount и reload, PostgreSQL подготовлен отдельным сервисом. Публичный локальный адрес — HTTP на loopback:8080; TLS и WebSocket пока не настроены.

Обновлять документ при изменении готовности компонентов; команды запуска описаны в README соответствующих частей проекта.
