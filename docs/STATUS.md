# Текущее состояние DevLab

Обновлено 30 октября 2026 года. Этот документ отражает реализацию, а не постоянные инструкции разработки.

- CLI: macOS + bash, выбор папки до запуска, PTY, чтение Git после команд и внешних изменений. Снимок сохраняется в `state.json`, правило добавляется в `.gitignore`. Добавлены каталог/выбор курса и подключение до папки; начальная сетевая версия каждого поколения — 1. Добавлены фоновая отправка последующих изменений, очередь последнего состояния на диске и автоматические повторы временных сетевых ошибок.
- Backend: `GET /api/v1/catalog` читает курсы из PostgreSQL; `POST /api/v1/git-course` создаёт/возвращает активную сессию и возвращает `{ "session_id": "UUID", "generation": 0, "steps": [...] }` из PostgreSQL с фильтром курса Git и сортировкой по position. Создание браузерной сессии реализовано; POST /api/v1/cli-connect выдаёт ключ и поколение; POST /api/v1/cli-send-snapshot принимает снимки. WebSocket и чтение снимка браузером ещё не реализованы. Каталог и шаги курса используют асинхронные SQLAlchemy-сессии. Подготовлены модели courses/course_steps и начальная миграция Alembic; применение выполняется вручную.
- Frontend: `/catalog` — каталог, `/git-course` — страница Git; `/` переводится в каталог. Страница Git отправляет POST, показывает идентификатор сессии и шаги из БД через API (блоки text/code) и пустые панели, без получения снимков CLI. Учебные материалы пока отсутствуют.
- Compose: nginx раздаёт сборку frontend, backend запускается с bind mount и reload, PostgreSQL подготовлен отдельным сервисом. Публичный локальный адрес — HTTP на loopback:8080; TLS и WebSocket пока не настроены.

Обновлять документ при изменении готовности компонентов; команды запуска описаны в README соответствующих частей проекта.

- Подготовлены контракт SnapshotReq/GitState, жизненный цикл в docs/practice-sessions.md и ORM-модели practice_sessions/practice_snapshots. Для новых таблиц создана миграция 8ca2ebb96c2b; хранится один последний снимок, без истории.

- Backend разделён на api/routes (ручки), api/schemas (контракты), db/models (таблицы), db/base.py, db/config.py и db/session.py. URL API и структура таблиц при переносе сохранены.

- Проверено реальное подключение CLI → backend и подтверждение начального снимка. HTTP/PTY-проверки CLI покрывают ошибки сети и локальный режим. Проверки всех конфликтов версий/поколений backend ещё предстоят.

- Постоянная доставка реализована только в CLI, backend не менялся. При 401/409 отправка приостанавливается без смены поколения. Ключ в памяти, неподтверждённое тело без ключа — в пользовательском каталоге DevLab. Браузер пока не получает снимки.
